# Restock Copilot

A decision-support tool for small shops that recommends what to reorder and explains why.

## Team areas

- `forecasting/` — data preparation and sales forecasting
- `engine/` — inventory decisions and replay evaluation
- `llm/` and `infra/` — AMD-hosted explanations
- `api/` and `web/` — backend and user interface
- `docs/` — contracts, assumptions, and project documentation
- `eval/` — evaluation results
