# Contracts

Changing any file in this directory (`docs/contracts/`) needs the Lead's approval.

This folder contains JSON Schemas and reference examples defining module boundaries across the pipeline:
- `forecast.schema.json` & `forecast.example.json`: Weekly unit demand forecasts (Forecasting / P1)
- `action.schema.json` & `action.example.json`: Inventory action decisions (Engine / P2)
- `explanation.schema.json` & `explanation.example.json`: Action explanations and verification (LLM / P3)
